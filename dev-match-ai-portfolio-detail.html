개발자 이력서 분석 및 인력 매칭 업무 보조 도구

금융 IT 개발자 인력 관리 및 소싱 업무 경험을 바탕으로, 이력서 확인부터 개발자 검색·추천·제출자료 생성까지 반복되는 업무를 하나의 흐름으로 정리한 웹 기반 업무 보조 도구입니다.

AI 업무자동화개발자 인력관리데이터 구조화Web App바이브코딩
01 · OVERVIEW

업무 경험에서 시작한 실무형 프로젝트

여러 이력서를 확인하고 고객사 조건에 맞는 개발자를 찾는 과정을 더 빠르고 일관되게 처리하는 것을 목표로 설계했습니다.

기획 의도

개발자 이력서의 경력·기술·금융업무 정보를 반복해서 확인하고, 고객사 요청마다 다시 후보자를 비교해야 하는 업무를 줄이기 위해 기획했습니다.

구현 방향

AI로 비정형 이력서와 고객사 요청사항을 구조화하고, 검색·추천·Excel/PDF 출력까지 하나의 웹 화면에서 이어지도록 구성했습니다.

담당 역할업무 프로세스 설계 · 기능 기획 · 화면 구성 · AI 프롬프트 설계 · 구현 및 테스트
사용 기술HTML · CSS · JavaScript · OpenAI API · Excel/PDF 처리
핵심 대상 업무금융 IT 개발자 이력서 관리 · 검색 · 고객사 인력 추천
표현 방식포트폴리오에서는 체험 링크 없이 화면과 프로세스 중심으로 소개
02 · WORKFLOW

업무 흐름

이력서 등록부터 고객사 제출자료 생성까지 6단계로 설계했습니다.

STEP 01이력서 등록PDF / DOC / DOCX
STEP 02AI 이력서 분석경력 · 기술 · 금융업무 · 프로젝트
STEP 03개발자 데이터 관리누적 · Excel 저장/불러오기
STEP 04조건별 검색등급 · 경력 · 기술 · 키워드
STEP 05고객사 요구 분석필수 · 우대조건 구조화
STEP 06적합 개발자 추천조건 비교 · 후보 선별
RESULT제출자료 생성Excel / PDF
03 · SCREENS

주요 화면

실제 프로그램 구조를 바탕으로 개인정보를 제외한 샘플 데이터로 구성한 포트폴리오용 화면입니다.

※ 화면의 인명·연락처·프로젝트 정보는 포트폴리오 표현을 위한 샘플 데이터입니다.

04 · PROBLEM / SOLUTION

반복 업무를 하나의 흐름으로 연결

단순한 AI 기능 구현보다 실제 업무에서 어디에 시간을 쓰는지부터 정리했습니다.

기존 업무의 불편함DEV MATCH AI 적용 방식
이력서를 하나씩 열어 경력과 기술을 확인AI로 핵심 정보를 항목별 데이터로 구조화
개발자 정보를 별도 파일에 다시 정리개발자 1명 = Excel 1행 형태로 누적 관리
고객사 조건마다 후보자를 수작업 탐색경력·등급·기술·금융업무 등 다중조건 검색
메일·문자 요청사항을 사람이 다시 정리AI가 필수조건·우대조건을 구조화
후보자 비교 후 추천명단을 별도 작성적합 후보 선별 후 Excel/PDF 제출자료 생성

이 프로젝트로 보여주고 싶은 역량

업무를 이해하고, 필요한 기능으로 바꾸어 구현했습니다.
