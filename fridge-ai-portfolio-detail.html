냉장고 AI 도우미

냉장고 사진을 바탕으로 식재료를 확인하고, 사용자가 직접 결과를 검토·수정한 뒤 활용 가능한 요리를 추천받는 웹 기반 생활 보조 도구입니다. 포트폴리오에서는 API 키 없이도 전체 사용 흐름을 체험할 수 있도록 데모 모드를 함께 구성했습니다.

핵심 기능사진 선택 · 식재료 확인/수정 · 요리 추천

1 OPENAI CONNECT

교육용 로컬 실습입니다.
실제 공개 서비스에서는 API Key를 브라우저에 입력하는 방식을 사용하지 마세요.
이 예제는 Key를 localStorage, sessionStorage, cookie, IndexedDB, URL에 저장하지 않습니다.
포트폴리오 데모 모드 · API 호출 없이 샘플 데이터로 기능 흐름을 체험하고 있습니다.
✓ OpenAI Connected · GPT-5

2 냉장고 사진

📷 JPG 또는 PNG 냉장고 사진을 선택하세요.
사진은 FileReader로 읽어 base64 data URL 형태로 API에 전달합니다.
AI가 냉장고 사진을 살펴보고 있습니다...

3 식재료 확인

AI 결과는 자동 확정되지 않습니다. 체크·수정·삭제하거나 직접 추가한 뒤 추천을 받으세요.

아직 분석된 식재료가 없습니다.
냉장고 사진을 선택하고 AI 분석을 실행하세요.
만들기 쉬운 요리를 고르고 있습니다...

4 AI 요리 추천

확인한 식재료를 바탕으로 요리 3개를 추천해드립니다.

교육용 예제 · API 사용량에 따라 OpenAI API 비용이 발생할 수 있습니다.
